# Product threat model
## Scope
Product ID/version; boundaries; intended/foreseeable use; owners; assumptions.
## Assets and data flows
List inputs, interfaces, remote processing, privileges, update channel and security-critical dependencies.
## Threat scenarios
For each: ID; attacker/objective; attack surface; preconditions; asset; impact on users; existing controls; risk-register ID; tests; alternative explanations.
## Approval
Architect; security reviewer; dated version; trigger for reassessment.
