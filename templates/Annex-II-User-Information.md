# Annex II user information checklist (starter)
- Manufacturer trade name and postal + electronic contact.
- Single point of contact for vulnerability reporting and CVD policy URL.
- Unique product name/type and version identification.
- Intended purpose, essential functionality and security properties.
- Significant foreseeable cybersecurity risks in intended use or misuse.
- Secure setup, operation, configuration, maintenance and updates.
- Support-period end date and communication channel.
- Instructions for decommissioning and secure data removal, as relevant.
- Information for integrators where relevant; SBOM access information if made available.
Verify every item against full Annex II; provide comprehensible language for targeted users/authorities.
Source: https://eur-lex.europa.eu/eli/reg/2024/2847/oj/eng
