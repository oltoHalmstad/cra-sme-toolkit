# Annex VII product technical documentation index (starter)
Product / version / responsible person / snapshot date:
1. General description, intended purpose, versions relevant to CRA; hardware illustrations if appropriate.
2. User instructions (Annex II) and disclosure contact; secure installation and operation.
3. Design/development/production and vulnerability-handling processes; architecture, integration and data flows.
4. Cybersecurity risk assessment and applicability of essential Annex I requirements.
5. Applicable standards/specifications, and description of solutions satisfying requirements.
6. Verifications/tests, test results and procedures; supply-chain/SBOM evidence.
7. Conformity-assessment route, certificates where needed and EU declaration of conformity.
8. Support period and processes for vulnerability handling and changes.
For each entry include file path, owner, revision, reviewed date and missing item. Read actual Annex VII; this checklist is non-exhaustive.
Source: https://eur-lex.europa.eu/eli/reg/2024/2847/oj/eng
