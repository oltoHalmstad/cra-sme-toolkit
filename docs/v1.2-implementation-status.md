## Remaining limitations (stated explicitly)
- **No legal sign-off.** The toolkit cannot complete P0-03. Until a qualified reviewer verifies the catalogue rows for the pilot scope, no product can reach PASS with the shipped catalogue. This is intended.
- **The mutation results are synthetic.** They verify the engine against faults the authors anticipated. The rate of such faults in real SMEs is unmeasured.
- **GitHub Actions behaviour is untested.** The v1.2 product workflow has been validated statically (YAML, pins, no silent paths) and its scripts are unit-tested, but it has not been run end to end on GitHub from this environment.
- **Exit-code assumptions.** `SUCCESS_EXIT_CODES` encodes the documented OSV-Scanner and Semgrep exit codes; re-check them on every tool upgrade.
