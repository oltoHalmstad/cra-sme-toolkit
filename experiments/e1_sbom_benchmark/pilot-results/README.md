# E1 pilot results (real tool output, 17 Oct 2026)
These are the raw CycloneDX outputs from cdxgen 12.8.6, cyclonedx-py 7.5.0 and cyclonedx-npm 6.0.1, run on the fixtures in `../fixtures/` inside a Linux sandbox. `runs.csv` holds the run log.

Redaction: one absolute sandbox path in `node-app.cdxgen.cdx.json` was replaced with `<FIXTURES>/`. No component data was changed. All other files are byte-identical to the tool output.

Scope: 3 fixtures. These results illustrate the measurement method and are not generalisable findings.
