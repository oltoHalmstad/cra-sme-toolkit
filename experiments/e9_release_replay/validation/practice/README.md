# Practice round (calibration) for the E9 manual validation

Three practice items let the raters try the coding guide (`../../VALIDATION.md`) before they start the real sample. They are drawn from the 128 unsampled `known_high` findings that share **no package and no vulnerability** with the 30 real items, so practising cannot leak answers. **They are not part of the analysis.**

## How to use it (about 45 minutes)
1. Each rater fills in their own sheet independently: `practice_rater_A.csv` or `practice_rater_B.csv`. Follow VALIDATION.md and record `label`, `evidence` and `minutes_spent`.
2. Only when **both** are done, open `DISCUSSION.md` together and compare your reasoning with the notes.
3. Clarify any rule that was unclear. **Do not change the coding guide.** It is part of the pre-registration.
4. Then start the real sheets (`../rater_A.csv`, `../rater_B.csv`) and work independently again.

Do not open DISCUSSION.md before rating; it contains suggested labels.
