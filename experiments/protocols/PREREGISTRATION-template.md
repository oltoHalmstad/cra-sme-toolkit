# Pre-registration — CRA-SME experiment E_ (adapted from the OSF pre-registration template)
1. **Title, authors, date, version**
2. **Research question(s) and hypotheses.** Give each one a direction and the smallest effect size of interest.
3. **Design.** Within- or between-subject; conditions; allocation (Latin square or randomisation seed); blinding.
4. **Participants / units.** Inclusion and exclusion criteria; recruitment channel; planned *n* with its justification (notebook 02 or 06 power simulation, with the parameters stated).
5. **Materials.** Versions of the toolkit, tools and scenario bank, given as commit hashes.
6. **Measures.** Exact definitions and formulas (concept note §8); how missing data is handled.
7. **Analysis plan.** Primary analysis, then secondary and sensitivity analyses. Effect sizes and CIs come first. Pin the analysis code to a commit of `crasme/` and the notebooks.
8. **Inference criteria.** For example, "H3a is supported if the 95% CI of Δα excludes 0."
9. **Exclusions and stopping rule.**
10. **Validity threats and mitigations.**
11. **Ethics and data protection.** Approval reference; consent; DPIA if personal data is processed; CVD handling of any real vulnerability found.
12. **Deviations log.** Fill this in during the study.
